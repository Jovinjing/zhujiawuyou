一、前端
1、环境要求
操作系统：window
版本要求：:vue3
编译工具：idea

2、安装过程
（1）下载vue源码导入idea
（2）在项目终端安装依赖：npm install
（3）本地开启项目 ：npm run dev


二.后端
1、环境要求
操作系统：window
版本要求：:jdk 21 mysql>=b.7.0 redis>=3.0 Maven>= 3.0 python>=3.0
编译工具：idea
2、安装过程
（1） 安装对应版本的jdk，python等
（2）下载源码并向idea导入
（3）打开项目运行 com.example.SpringbootApplication


三、微信小程序
1、环境要求
操作系统：window
编译工具：微信开发者工具
2、安装过程
（1）下载源码后导入微信开发者工具
（2）左上角微信扫码登录微信开发者工具并注册
（3）点击软件上面的编译按钮运行代码
